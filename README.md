# 🎓 EDUPATH – Student Career Guidance, Mentorship & College Discovery Platform

### 🌟 Discover Your Path. Design Your Future.

**Edupath** is an online student career guidance platform designed to help students discover their interests, explore suitable courses and career opportunities, connect with experienced seniors as mentors, and make informed educational decisions.

Our goal is to guide students from confusion to clarity by providing career exploration, personalized recommendations, mentorship support and college discovery in one platform.

---

## 🎯 Project Objectives

- Help students identify their interests, strengths and career preferences.
- Recommend suitable courses and career paths based on students' interests.
- Connect students with experienced seniors and mentors.
- Provide guidance for academic and career planning.
- Help students explore and compare colleges.
- Create personalized career roadmaps for future development.

---

## ✨ Key Features

### 1. 🎯 Career Guidance
- Explore different career opportunities.
- Discover courses based on interests and strengths.
- Complete career assessments.
- Receive personalized career recommendations.

### 2. 👩‍🏫 Student–Mentor Interaction
- Student and mentor registration.
- Explore mentor profiles and expertise.
- Connect with experienced seniors.
- Book mentorship sessions.
- Interact through messaging.

### 3. 🏫 College Discovery
- Explore colleges across India.
- Search colleges based on courses and streams.
- Filter and shortlist institutions.
- Compare college options.

### 4. 🧭 Personalized Career Roadmaps
- Identify academic goals.
- Understand possible career pathways.
- Plan future learning steps.
- Track career exploration progress.

### 5. 📊 Student Dashboard
- Personalized student dashboard.
- Career recommendations.
- Saved colleges and careers.
- Upcoming mentorship sessions.
- Notifications and profile management.

### 6. 🌙 Additional Features
- Student and mentor login.
- Dark mode.
- Search and filtering options.
- Profile management.
- Responsive user interface.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git
   ```

2. Open the project folder.

3. Make sure the required project files are present:
   - `index.html`
   - `style.css`
   - `script.js`
   - `supabase-config.js`

4. Configure your Supabase project credentials in `supabase-config.js`.

5. Open `index.html` using a browser or run the project using the VS Code Live Server extension.
